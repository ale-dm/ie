# 5. Modo Fatal: Combate 1vs1 (11 Rondas)

El Modo Fatal se desarrolla en 11 duelos individuales por turnos, con dos barras de recursos compartidas por el equipo.

```
┌─────────────────────────────────────────────────────────┐
│               SISTEMA DE RECURSOS FATAL                 │
├─────────────────────────────────────────────────────────┤
│  [ Duelos 1vs1 ] ────> Generan TENSIÓN (20 a 100)       │
│                             │                           │
│                             ▼                           │
│  [ Supertécnicas ] ───> Gastan TENSIÓN                  │
│                         Cargan HIPERENERGÍA             │
│                             │                           │
│                             ▼                           │
│  [ Hiperenergía ] ───>  Gastas Cargas (Máx. 2)          │
│                         Activas Transformación Especial │
└─────────────────────────────────────────────────────────┘
```

## 5.1 Barra Global de Tensión

- **Inicio de partido:** 20 / 100.
- **Ganar un duelo:** +25.
- **Perder un duelo:** +10.
- **Uso:** se consume para activar las Supertécnicas de la carta en el turno (el coste no varía con el grado).

## 5.2 Barra de Hiperenergía (máx. 2 cargas)

- **Carga:** +1 cada 2 Supertécnicas usadas (acumulativo en el partido).
- **Uso:** gastar 1 carga activa el estado especial de la carta (Keshin, Mixi-Max, Armadura, Tótem o Despertar) en esa ronda, aplicando sus modificadores.

## 5.3 Por definir

- Resolución de un duelo (qué stat se enfrenta a cuál, aleatoriedad).
- Condición de victoria (¿goles?, ¿duelos ganados?) y desempates.
- Coste de Tensión por tipo de técnica y modificadores de cada transformación.
